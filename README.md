# Gooo meta-operator typechecker

This repository is a small, falsifiable boundary for higher-order
self-improvement operations. It treats a meta-operation as a typed value and
checks its stage, origin, capabilities, effect row, preconditions, and
postconditions before executing it.

The authority chain is:

```text
authoritative .gooo source → typed meta IR → proof-carrying Go executor → compiler fixture → verifier
```

The `.gooo` source declares the kinds and types, effect rows, stage indices,
origin identities, capabilities, composition rules, fixed seven-case
denominator, and `REFUTED > UNKNOWN > CLOSED` precedence. Go only parses,
lowers, executes, and verifies those declarations. The JSON contract is a
transport/CI identity check; it does not define semantic rules.

## Fixed conformance vector

The repository has exactly seven cases:

| ordinal | case | expected terminal state |
|---:|---|---|
| 1 | identity-composition | `CLOSED` |
| 2 | disjoint-effect-composition | `CLOSED` |
| 3 | capability-polymorphic-instantiation | `CLOSED` |
| 4 | stage-escape | `REFUTED` |
| 5 | origin-capture | `REFUTED` |
| 6 | unbound-capability | `UNKNOWN` |
| 7 | replay | `CLOSED` |

`CLOSED` is not awarded by typechecking alone. The generated executor must
apply the proof to `fixtures/compiler/input.gooo`, return the declared
terminal reason, reproduce the declared effect trace, and produce the
declared compiler output. Replay additionally requires the exact artifact
digest to match.

Every `UNKNOWN` carries `stage`, `step`, `reason`, `unknown_class`,
`next_operation`, and `blocked_by`. No score, weighted average, or estimated
percentage is emitted.

## Commands

Compile the source into caller-owned output paths:

```sh
go run ./cmd/gooo-meta-operator-typechecker compile \
  -source examples/meta-operator-typechecker-v1/main.gooo \
  -contract contracts/denominator-v1.json \
  -output-ir /tmp/semantic-ir.json \
  -output-go /tmp/meta.gooo.go
```

Typecheck a case or all proofs:

```sh
go run ./cmd/gooo-meta-operator-typechecker typecheck \
  -source examples/meta-operator-typechecker-v1/main.gooo \
  -contract contracts/denominator-v1.json \
  -case replay
```

CI runs build, tests, vet, source-to-generated equality, semantic audit,
integration execution, and conformance. Conformance writes only to an empty
caller-owned temporary directory and records exact integer inventory,
generated bytes, per-stage `wall_ms`/`peak_rss_kib`, test fields, and the fixed
case vector. Root `README.md` is excluded from inventory by declaration. Local
development authority is zero, including `local_integration_executions=0`;
integration is exercised only by GitHub Actions.

This tool does not claim that a general self-improvement system is safe. Its
claim is narrower: these seven declared typed meta-operation boundaries can be
accepted or rejected reproducibly against one compiler fixture.
